📡 Đồng bộ dữ liệu

Kết nối Google Sheets để đồng bộ dữ liệu giữa nhiều thiết bị. Vợ chồng, gia đình có thể cùng quản lý chi tiêu chung.

⏳ Đang kiểm tra...
📖

Hướng dẫn kết nối Google Sheets (6 bước)

Bấm để mở / đóng chi tiết các bước
▼
1
Tạo Google Sheet mới

Mở sheets.new → đặt tên "CashFlow"

2
Mở Apps Script

Trong Google Sheet → Menu "Tiện ích mở rộng" → "Apps Script"

3
Dán code

Xóa nội dung cũ → dán code bên dưới → nhấn 💾 Lưu

4
Chạy setupSheet

Trong Apps Script → chọn hàm "setupSheet" từ dropdown → nhấn ▶️ Run → cấp quyền khi được hỏi

5
Triển khai (Deploy)

Nhấn Triển khai (Deploy) → Tùy chọn triển khai mới (New deployment):

• Chọn loại: Ứng dụng web (Web app)

• Thực thi dưới tên (Execute as): Tôi (Me)

• Ai có quyền truy cập (Who has access): Bất kỳ ai (Anyone) (Rất quan trọng!)

→ Nhấn Triển khai (Deploy) → Sao chép URL ứng dụng web

6
Dán URL

Dán URL vừa copy vào ô phía trên → nhấn "Kiểm tra" → Xong! 🎉
